---

## 1. 设计目标与原则

1. **轻量务实**：不做花哨，把"建 Key → 绑额度 → 配路由 → 看用量"核心流做顺。
2. **信息透明**：成本、错误率、额度状态一眼可见；非 OpenAI 模型的估算值明确标注。
3. **防误操作**：破坏性操作（删 Key、禁用 provider）有二次确认；敏感信息（Key 明文）仅创建时展示一次。
4. **角色分级**：admin 全功能；user 仅自身用量视图，无管理配置入口。

## 3. 核心用户流程

### 3.1 主线：建 Key → 绑额度 → 配路由 → 分发

1. **管理员登录**控制台。
2. **新建虚拟 Key**：填写名称 → 选择绑定账号（默认自己）→ 设置每日额度（token 或金额，可留空=不限制）→ 启用。
3. **（首次/变更时）配置路由别名**：在"路由策略"新建别名（如 `fast-chat`），指定候选 providers 与顺序、策略（weighted / cost / failover）。
4. **复制 Key**：创建成功页**仅一次**展示明文 Key + 复制按钮 + 警告"请妥善保存，关闭后不可再查看"。
5. **分发给开发者**：把 Key 与对应别名（或默认模型）告知组内同事。
6. **开发者接入**：将应用 `base_url` 指向网关，模型名填别名，即可调用，无需改业务代码。

> 流程图见文末 §6 与下方内联图。

### 3.2 运行时：开发者接入与额度耗尽自动切换

- 开发者用 Key 调用别名 `fast-chat`。
- 网关路由到主 provider；若该 provider **token 额度耗尽**（识别错误码），网关：
  1. 将该 provider 标记为「额度耗尽 / 暂不可用」；
  2. 自动 fallback 到同别名下下一个可用 provider；
  3. 返回结果，调用方无感。
- 标记可在额度恢复后**自动探活清除**，或管理员在 Provider / 路由页**手动重置**。

### 3.3 查看用量与成本

- 管理员在"用量 / 成本报表"按 Key / 模型 / 时间聚合查看；非 OpenAI 模型金额标注「估算」。
- user 在自身视图查看自己 Key 的用量与花费。

## 4. 关键页面设计要点

### 4.1 概览 Dashboard（首屏）
- 四个核心指标卡：今日调用量、今日花费、错误率、活跃 Key 数。
- 下方"近期异常"列表：展示被标记「额度耗尽」的 provider / 模型，附"重置"按钮。
- 空状态：无数据时显示引导"先创建一个虚拟 Key"。

### 4.2 虚拟 Key 管理
- **列表**：Key（掩码 `sk-****1234`）、所属账号、状态徽标（启用/禁用）、每日额度、今日已用/剩余、创建时间。
- **新建表单字段**：名称（必填）、绑定账号（下拉，admin 可选他人）、每日额度（选填，单位 token 或 ¥）、启用（默认开）。
- **详情**：用量趋势、重置 Key（生成新明文，旧 Key 失效）、启用/禁用、删除（二次确认）。

### 4.3 Provider 配置
- **列表**：id、类型、权重、状态（启用/停用/额度耗尽 徽标）、操作。
- **编辑**：凭证引用（填写环境变量名，如 `OPENAI_API_KEY`，**不填真实 key**）、权重、启用开关。
- 状态徽标「额度耗尽」可点击重置。

### 4.4 路由策略（重点）
- 别名编辑核心控件：**候选 provider 有序列表**（可拖拽/上下调序决定 failover 优先级）+ **策略选择**（weighted / cost / failover）。
- 明确提示：列表第一项为首选，后续为 fallback 顺序。

### 4.5 用量 / 成本报表
- 三个维度切换：按 Key / 按模型 / 按时间。
- 表格列：维度项、调用次数、prompt tokens、completion tokens、花费（估算标注）、错误率。
- 时间筛选：日 / 周 / 月；导出 CSV（可选）。

### 4.6 账号管理（admin）
- 列表：用户名、角色（admin/user）、状态、创建时间。
- 新建：用户名、角色、初始口令；禁用 / 改角色。

## 5. 关键交互与状态

| 场景 | 处理 |
|------|------|
| Key 明文展示 | 仅创建成功页一次；复制按钮；警告提示 |
| 删除 / 禁用 | 二次确认弹窗，显示影响范围 |
| provider 全部不可用 | 网关返回 `502` + 错误明细；控制台"近期异常"提示 |
| 某 provider 额度耗尽 | 徽标标记 + 自动切换 + 可手动重置 |
| 限流命中 | 调用返回 `429` + `Retry-After`；控制台额度进度条预警 |
| 加载 / 错误 / 空 | 统一骨架屏、错误重试、空状态引导 |

## 6. 布局与导航

- **左侧固定导航**：一级菜单（Dashboard / Key / Provider / 路由 / 报表 / 账号）。
- **顶部栏**：当前账号名 + 角色徽标 + 退出。
- **内容区**：卡片化布局，桌面优先（内部管理台，响应式非必须）。
- **设计规范（轻量）**：建议 Tailwind + 轻量组件；配色克制，状态用色（绿=正常/红=异常/黄=警告）。
